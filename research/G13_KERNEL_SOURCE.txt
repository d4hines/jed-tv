G13 kernel sources and newer firmware candidates
2026-11-01

RESULT

No exact public source release for this unit's installed TCL V013 kernel
was found. There is a credible Android 14 / Linux 5.15 MT5867 porting base:
techyminati/android_kernel_oneplus_mt5867, branch android-14.0. It is much
more complete for this hardware than TCL's published mt9221U repository.
It has now been compiled with the saved G13 configuration and booted to
BusyBox PID 1 on the partial MT5867 QEMU machine. Four CPUs, timers, child
execution, tmpfs and sync debugfs passed. See research/g13-kernel/README.txt
for the required build repairs, exact evidence and hardware limitations.
No physical G13 boot with this kernel has been attempted.

Subsequent QEMU work merges pinned Android-common updates to Linux 5.15.220
and boots a small ARM32 Android 16 native userspace. Android init, property
events, concurrent Binder calls and shared-memory descriptor transfer pass.
See research/g13-android16/README.txt for source pins, reproducible commands
and the remaining vendor/HAL limitations. This does not establish physical
TV or proprietary module compatibility and does not replace the V033 finding.

A newer exact-platform binary package is available: official TCL T221T10
V033, containing Linux 5.15.180-android14-11 and Android 14 userspace AU21.
This is the best identified candidate for trying a newer vendor kernel.
It is a firmware update, not a source release. No installation, reboot,
partition write, UART access, or change to the native launcher was made.

The root Makefile reports Linux 5.15.148. The May 1, 2025 import commit

14 release 2503121853 and BSP "OPPO 9216 TV U_14". Subsequent commits import
the Dubai defconfig and MStar drivers. This is the maintainer's provenance
statement, not independent verification against an original OPPO archive.

The full archive was inspected, avoiding GitHub recursive-tree truncation:
  85,579 archive entries; 1,756 Kconfig-named regular files
  177 regular files specifically under mstar2/hal/mt5867/
  all 147 active CONFIG_MSTAR_*, CONFIG_MP_*, CONFIG_MS_* symbols from
  the live TV have definitions somewhere in the published Kconfig files
  all those 147 values also match arch/arm/configs/dubai_defconfig

This count checks definitions and saved values, not Kconfig reachability,
link success, hardware behavior, or ABI compatibility. The tree includes
MT5867 CPU/board code, Ethernet, GPIO, IR, eMMC/SDIO, USB, timers/power,
GOP graphics, ALSA audio, DMIC, and other HAL directories.

Concrete build gaps and cautions:
  - drivers/mstar2 and arch/arm/mach-mt5867 are absolute symlinks into
    /home/ubuntu/ack. Raw GitHub requests through them return 404 although
    their targets exist under the repository's root mstar2 directory.
    research/g13-kernel/prepare.py now safely relocates these links.
    The build skips genlink.sh because it mishandles an O= output directory.
  - drivers/mstar3party points to /home/ubuntu/ack/mstar3party, but the
    root mstar3party directory is absent. No Kconfig or Makefile references
    were found, and it is not required by the successfully built G13 config.
  - dubai_defconfig's header says 5.15.90 and records Clang r475365b,
    while the tree's Makefile says 5.15.148 and build.config.constants
    selects r487747c. Our captured G13 configuration/toolchain identity
    is the better starting point for a G13 build audit.
  - No matching complete TCL userspace/module source set was identified.
    Existing binary modules require an explicit ABI compatibility check.
  - 5.15.148 is older than the installed 5.15.167. Moving this driver-bearing
    tree to 5.15.180 or later requires integration and validation; it is
    not an already published, tested newer G13 kernel.

The OTA is a full A/B package for G13_2K_US. Its 19 partitions include
boot, init_boot, vendor_boot, dtbo, vendor_dlkm, system_dlkm, vendor,
system, system_ext, product, linux_rootfs_a, and tvservice. Thus it supplies
the vendor's userspace/module set along with the newer kernel. It also
contains mboot; it must not be treated as a kernel-only update.
