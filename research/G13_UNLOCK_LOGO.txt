Exact V013 layout and validation
-------------------------------
AVBPanelLogo at 0x274c7714 invokes avbShowStatus 0 0 1 1 2 for the unlocked
state. do_avbShowStatus at 0x27403474 selects chunk-header words 0x27/0x28:
JPEG offset 0x2bfa00, length 47903. The original 720x480 image reads "Your
device has been unlocked and can't be trusted. System will boot up
continuously." The display routine reads this asset directly from MBOOT.
BootlogoFile only affects AVBPanelLogo's normal/green branch.

The replacement is padded with zero bytes after the JPEG end marker to fill
the existing slot. It changes 45401 bytes relative to stock, all inside that
slot. The write spans 94 sectors of 512 bytes, starting at sector 5629,
preserving the original 225 bytes following the asset. Total: 48128 bytes.
No header, executable instruction, signature or other asset was changed.

MBOOT's header describes executable bytes [0x2400,0x2bf860). Its SECURITY
record starts at 0x2bf860 and records version 1 and code length 0x2bd460;
the following 256-byte signature ends at 0x2bf970. The asset starts at
0x2bfa00. These boundaries and the unchanged partition tail are checked by
the builder. It also executes the exact V013 display command and chunk
getter in Unicorn against stock and candidate images. Both read the same
slot and reach the display call; Pillow decodes the JPEG. Hardware calls
are stubbed in that test. The subsequent real reboot and owner observation
establish the actual device result separately.

Apply and rollback
------------------
The helper checks exact device identity, slot, known full-image hashes,
partition bounds, native startup, unchanged init_boot and stock backup
bootloaders. It saves a fresh full readback and both sector spans, then runs
a detached on-TV transaction. A failed verification restores the previous
span while Linux is still running. Power-loss recovery is not provided by
that transaction. Full host readback must match before rebooting.

  nix develop -c python3 tools/native-app/g13-unlock-logo.py apply --logo lean
  nix develop -c python3 tools/native-app/g13-unlock-logo.py apply --logo tcl
  nix develop -c python3 tools/native-app/g13-unlock-logo.py restore

The first command installs Lean (and is a no-op if already installed);
the second restores the tested TCL artwork; the third restores the original
unlocked warning. None reboots automatically. After a verified write, use
normal reboot with UART capture, then restore host services:

  nix develop -c adb -s 192.168.77.3:5555 shell 'sync; setprop sys.powerctl reboot'
  nix develop -c python3 tools/native-app/run-g13.py --network-only

Do not relock, change AVB policy, flash a whole bootloader for this logo,
touch MBOOT_b/MBOOTBAK, or substitute G06 firmware. Read RECOVERY_NOTES.txt
before future boot-state changes. USB remains the verified Fastboot path;
this write uses rooted Android ADB over Ethernet, not Ethernet Fastboot.
