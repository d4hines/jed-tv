Changes (only src/slides)
------------------------
- image_build.rs: new host-only helper shared by build.rs and unit tests.
  Validates exact P7/8-bit/RGBA contract, positive bounded dimensions,
  duplicate fields and exact payload length, with checked multiplication.
  Conversion now passes -nostdin to ffmpeg for automated builds.
- build.rs calls the helper and preserves FILE:LINE failure diagnostics.
- src/lib.rs includes the helper under cfg(test) only. No conversion code
  or external process launcher is added to the TV runtime.
- src/render.rs fixes bilinear interpolation of transparent images:
  interpolate premultiplied colour so hidden RGB under a transparent pixel
  cannot tint an adjacent visible pixel. Output remains ordinary RGBA.
- Added host tests for malformed/truncated/oversized PAM, transparent-edge
  colour correctness, and PNG -> conversion -> image block -> full renderer.
  The PNG test also creates an inspectable slide preview in assets/.
