Scope and storage
-----------------
Companion to G13_RESEARCH_HANDOFF.txt, describing the checkpoint through
c60b635, rebased onto main revision 76c5a57. Paths below are repository-relative
unless absolute. This is an index of available material, not a work queue.

Authored scripts and notes are tracked in Git. Firmware, captured device
inputs, extracted trees, builds and result JSON/logs are under ignored
assets/. A Git checkout alone therefore does not contain the tested images
or all reproduction inputs. Several retained private inputs resolve to
/home/eduardo/tv_hack/assets/ through local symlinks.

The documented build host is ARM64 NixOS. Each experiment has an existing
Nix environment/reproduction guide. The larger new preparation scripts
check working headroom above the owner's 15 GiB free-space reserve; this
is a preflight check, not a filesystem quota. No large build or extraction
was performed while writing the original handoff. The subsequent 5.15.224
build used the owner's x86_64 NixOS VM, as documented below.
