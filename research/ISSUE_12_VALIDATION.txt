Issue 12 confinement foundation: validation, 2026-11-01
=====================================================
Branch: d4hines/pid1-demo. No TV access, flashing or live boot changes.

Public, firmware-free checks:
  nix run .#lean-check
  nix run .#pid1 -- --check-supervisor
  nix run .#pid1 -- --check

Native checks pass 193536 menu, 80387 supervisor and 393567 seccomp BPF
executions. Both ARM and AArch64 filter instruction streams are interpreted;
actual execution is ARM32. No Lean runtime/allocator imports in scalar policy.

The hostile app verifies UID/eUID=10001, fork/vfork/process clone return EPERM,
clone3 returns ENOSYS, execve and nonreserved execveat return EPERM, reserved
launch fd is closed and cannot be recreated, absolute-path execveat receives
EACCES on noexec mounts, /proc/self/exe is absent, raw input and another UID's
private directory return EACCES, a thread can run, and SIGTERM can be ignored.
The launcher handles duplicate Home, escalates to KILL and opens Slides next.
The ordinary graphical tour covers generated video/audio, Home, Slides and
Doom. It requires Doom engine initialization AND its tic/frame report before
returning Home; opening the framebuffer alone is not considered success.
C stdio requires readv; ARM signal handlers require legacy sigreturn as well
as rt_sigreturn. Both old and time64 clocks are allowed for 4.19 fallback.

confirmed uid10001 YouTube, uid10002 Doom, uid10003 Slides, with
